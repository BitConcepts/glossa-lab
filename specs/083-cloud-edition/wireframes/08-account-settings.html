Annotation — wireframe 08 · not part of the UI
Purpose
Self-service for the one identity each user owns: profile, password, sessions, and their own audit slice (FR-004).
Primary action
Per-section saves (quiet pattern carried from Spec 081's Settings screen); “Change password” is the security-primary.
Changed & why
New surface, split out of Settings on purpose: Spec 081 separated tool settings from program settings; the cloud adds a third kind — account settings, which belong to the person, not the tool or a program. Username immutability is stated where a user would try to change it, with the reason (it is the attribution name — C083-11 makes names load-bearing, so they cannot drift). Session lifetime copy states decision D-3 in the UI.
Spec claims
C083-4 (sessions: lifetime, revocation, password-change invalidation), C083-12 (the activity card is the audit log, personal slice), C083-11 (username as attribution anchor).
