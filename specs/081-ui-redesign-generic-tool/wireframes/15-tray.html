Wireframe 15 is a spec sheet for the system-tray surface — the tray has no page of its own, so its surfaces (icon, tooltip, menu, status texts) are specified here at full fidelity.

Tray — icon, tooltip, menu

The tray is the service's handle on the desktop: it starts the backend, supervises it, and reports its state. In the redesign it also names the open program — the person at the machine should be able to see which work the healthy service is serving. It stays a status-and-control surface: no research work moves into the tray.

Status lines — every state, in words

Healthy“Indus Script — backend healthy · v0.1.0 · up 5 h 50 m” (uptime humanized; raw seconds never shown)
DegradedNames the failing check, e.g. “backend degraded — database read-only”. Clicking the line opens Status.
Stopped by user“Backend stopped by you — it will not restart itself.” The supervision never overrides a person's stop.
Stopped — limit“Backend stopped — auto-restart limit reached (3 in the last hour).” Clicking opens Status & the session log.
Starting“Backend starting…” for the bounded start window only; a start that never verifies becomes Stopped with its reason, never a permanent spinner.

One instance. Starting the tray when one is already running focuses the existing tray instead of adding another — the 2026-10-29 start tests accumulated three trays; the redesign makes accumulation impossible by construction, and the installer/start path checks for it.

Annotation — wireframe 15 · not part of the UI
Purpose
Supervise the service from the desktop: state at a glance, start/stop/restart, and a door into the framed status view.
Primary action
“Open Glossa Lab” (the menu's default, bold item). The tray deliberately gets no research actions.
Changed & why
Four changes from today's tray: (1) the status line and tooltip name the open program — healthy for what; (2) uptime is humanized (“up 5 h 50 m”, not “up 1803s”); (3) “View Log” becomes “View status & session log” and opens the framed Status screen instead of dropping the raw cumulative file into a text editor — the exact route by which historical errors read as current failures; (4) single-instance is specified, closing the tray-accumulation finding. Menu structure, port display, change-port dialogs, autostart toggle, supervision cap (3/hour, user stop never overridden) are unchanged — they work.
Spec claims
C081-3, C081-7, C081-12 (tray single-instance + program named in status).
