Sign in

Glossa Lab is invitation-only. Sign in with the username and password you set when you accepted your invite.

Specimen error state: “That username and password don’t match our records. Check them and try again.” — one message for both failures; the form never says which half was wrong.

Forgot your password? An admin can issue you a reset link from the user dashboard.

glossa.bitconcepts.tech · This site is deliberately not indexed by search engines, and there is no public registration — accounts are created from invite links only.

Annotation — wireframe 01 · not part of the UI
Purpose
The only door in. Authenticate a user (Spec 083 FR-004) and, by what it does not offer, state the registration policy: no sign-up link exists anywhere in this edition.
Primary action
“Sign in”.
Changed & why
New surface — the desktop edition has no login (Spec 082's token rides in a URL fragment from the tray). The cloud edition's credential is a user session in an HttpOnly cookie, so this screen replaces the fragment handoff entirely for browser users; the token is never accepted here (FR-008). The single undifferentiated error message is deliberate: the form must not confirm whether a username exists.
Spec claims
C083-4 (session perimeter), C083-7 (noindex — the footer states it in words as well as headers), C083-8 (credential separation), C083-12 (failed logins are audit-logged).
