Glossa Lab v0.1.0 · TRISTEN-DESKTOP · checked 14:02

Glossa Lab is ready. The work starts with a program.

Glossa Lab is a workbench for evidence-tested research. A program is one research effort inside it: a question, the claims that test it — each registered with the evidence that could prove it wrong — and the record of what people have settled. No program exists yet on this machine.

Start a program

You need two things. Everything else — data, claims, experiments — is added inside the program, as the work grows.

1 · A name
Short and plain: the effort's name, as you would say it.
2 · The question it tests
One sentence. It appears on the program's home and in the switcher, so it should say what would count as an answer.

Or bring existing work

A project folder from the current version imports as a program: its topics, corpora, experiments, and records keep their names and dates. Importing never renames anything silently — the import report lists every item and where it landed.

The service underneath is already verified: Glossa Lab v0.1.0 on this machine, data folder %LOCALAPPDATA%\GlossaLab\data, checked just now. Details live under Status — you do not need them to begin.
