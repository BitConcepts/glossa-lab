## 5. Double derivation of the acceptance tests (doctrine record)

Per the autonomous-execution doctrine, each
claim's acceptance test was derived twice,
independently, from the requirement alone,
before the register was written:

- **Derivation A** worked from the
  requirement text forward: for each claim,
  what observable record, produced by the run
  itself, would show the requirement held?
- **Derivation B** worked from the falsifier
  and the pre-written outcome wordings
  backward: for each claim, what would a
  hostile reader check in the outcome record
  to show the requirement had *not* held?

The two derivations agreed on the gate,
count, and inspection tests for F065-C01,
C02, C03, C04, C05, C08, C11, C12, C13, and
C15 without amendment: in each case A's
"record produced in order" and B's "absence
or disorder of that record falsifies" are
the same check read from the two directions,
and the register states it once.

Disagreements, and their resolutions:

- **X-1 — What does S-5's row rest on?** A,
  reading the established edition
  relationship, let the S-5 search run on the
  held cleaned text (content-equal, already
  in the repository, already pinned by 057).
  B held that this re-runs exactly the search
  057 ran and calls it step 4: 057's step 4
  names the *document's* text layer, and the
  acquired file — a different byte object, a
  Print-to-PDF rendering — is the document in
  hand. **Resolution:** B governs
  (DD-065-3): the acquired file is asserted
  at gate 0.2 and searched; the held text is
  never substituted, and a host without the
  file closes the run at step 0.
- **X-2 — Is the blocked S-1 row a result or
  an interruption?** A scored a run in which
  S-1 is never searched as incomplete — the
  accounting falsifier (§1.3) unmet — because
  the row carries no search evidence. B held
  that the frozen contract is the accounting:
  the row's outcome is decided by the intake
  determination at gate 0.3, its evidence is
  the blocker record, and a run that treated
  the blocked arm as failure would either
  stall forever on an owner act or pressure
  an executor toward the contacts and
  accounts §9.6 forbids. **Resolution:** B
  governs (DD-065-6): STILL UNLOCATED —
  ACQUISITION BLOCKED is a frozen outcome of
  the row; the headline partition (§7)
  includes class B as a result, and the
  falsifier is read over the contract —
  each row ends with exactly one outcome
  *derived from the search the contract
  states, or from the frozen blocked

- **X-3 — When both rows resolve absent,
