Annotation — wireframe 05 · not part of the UI
Purpose
Create and govern the edition's only entry tickets (FR-002): single-use, expiring, revocable links into named programs.
Primary action
“Create invite link”, then “Copy link”.
Changed & why
New surface. The form's wording carries decision D-2 in the UI itself (email optional, "the link is what counts"), so nobody has to remember the policy. The one-time link panel is the C083-2 hash rule made visible: because only the hash is kept, the full link exists exactly once — and the UI says so at the moment it matters, with revoke-and-reissue as the stated recovery. A dashboard that could re-display live invite links would be a standing credential store; this one is not.
Spec claims
C083-1, C083-2 (lifecycle + hashed storage), C083-12 (create/redeem/revoke are audit events).
