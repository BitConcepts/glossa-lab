## 1. Population and bound

The register covers **every distinct raw `material` value in
the pinned corpus snapshot** (SHA-256 `08fc96c8…`, T101
census): **1,122 distinct values over 11,839 records**. It is
bound to that population. The CISI data-list compilation's
23 raw material values (T101 §5) are a DIFFERENT population
and are NOT covered: a Stage 4 pass over the T103 join needs
a successor register version or an amendment covering them
first. This bound is stated, not repaired.

The mapping is LEXICAL: it classes the words the catalogues
use, with documented synonym routes where the trade name is
settled (soapstone and clinoenstatite → steatite; flint →
chert; bloodstone/heliotrope → jasper; rock crystal →
quartz; albite → feldspar; latten → brass; electrotype →
copper; lapis lacedemonius → basalt, its historical referent;
grahamite → bitumen; goethite/limonite/magnetite/
menaccanite/ochre → iron-oxide; sard → carnelian). It is
not a geological determination of any object.

## 3. Rules (as frozen in the artifact)

1. Clean: whitespace normalized (the raw table keys are the
   values exactly as recorded — two carry a leading space,
   ` Iraq` and ` Restaurants 141`, and are dispositioned
   under their raw keys).
2. Uncertainty read from the raw value: markers `(?)`,
   `(uncertain)`, `?`, `possibly`, `probably`, `probable`.
3. Whole-value non-material patterns fire first, in order:
   NM-DATE (date/period strings), NM-PERIOD (period labels),
   NM-EXCAV (excavation-context and code strings),
   NM-FRAGMENT (the bare marker 'Fragment.').
4. Parenthetical spans are then read for glosses — a firing
   gloss (`unfired`/`un-baked`) governs the clay family; a
   variety gloss replaces the family head it glosses
   ('Chalcedony (carnelian)' is carnelian) — and removed.
5. Print/drawing technique phrases are masked ('wood
   engraving', 'etching', 'commercial color lithograph',
   'salted paper print', 'glass negative', …): techniques
   are not materials.
6. Class keywords match case-insensitively with word
   boundaries; overlapping spans resolve longest-first
   ('copper alloy' over 'copper'; 'plaster of paris' →
   gypsum over 'plaster'; 'hard-paste porcelain' → ceramic
   over 'paste').
7. Clay family: `clay` + `clay-unfired` evidence collapses
   to clay-unfired; a parenthetical unfired marker converts
   a plain clay match ('Clay (unfired)', 372 records).
8. Surface-media keywords (paint, pigment, ink, slip,
   glaze, gilt, gesso, tempera, gouache, watercolor, pastel,
   graphite, wash, …) are RECORDED per value, never classed.
   A value naming only surface media is non-material
   (NM-MEDIUM, 'Pen and brown ink' and its kin).
9. A value left with no class, technique masks only, and
   only function words is non-material (NM-TECH: the
   etching-state series, 'Commercial process', 'Drypoint').
10. Kind: exactly one class → `class`; two or more →
    `composite` (the component set IS the composite split);
    a single-component value joined by 'or' → `alternatives`
    (the cataloguer's alternatives, marked uncertain).
11. Anything no rule dispositions is `unmapped`, and the
    register names it with its reason — the frozen unmapped
    set is part of the rules (the builder fails if
    computation produces a different set).

## 4. Disposition counts (computed)

| kind | values | records |
|---|---|---|
| class | 663 | 10,987 |
| composite | 370 | 638 |
| alternatives | 15 | 29 |
| non-material | 49 | 157 |
| unmapped (named, with reasons) | 25 | 28 |

Uncertain-flagged: 139 values, 233 records. The largest
classes by records: steatite 3,095; clay-unfired 1,206;
ceramic 1,121; terracotta 1,027; composite-carried counts
are per class in the artifact (a record counts once per
class its value names). One derived subpopulation worth
naming for later stages: values classed steatite carrying
the glaze surface marker — the glazed-steatite population
('Steatite (glazed)' 273 records, 'Glazed steatite' 167,
and kin) — recorded per value in the artifact's
`surface_media`, not as a class, because glazing is a
surface treatment in the catalogues' own language.

The 25 unmapped values (28 records) are geographic,
provenience, and cultural labels ('Caribbean',
'India,Haryana,Rakhi Ghari', 'Iraq,Tepe Gawra', 'Eskimo',
'Assyrian', …), uninterpretable fragments ('Ao'), an
object-form word ('Galley'), an unexplained string
(' Restaurants 141'), unspecified mineral grains
('Magnetic Grains'), and one unresolvable stone trade name
('Almondstone') — each with its reason in the artifact.

## 5. Acceptance checks (T102) and their execution

The register's falsifier, run by
`tools/spec093/check_material_register.py` — an independent
implementation that reads the rules ONLY from the artifact:

1. the register's value set is exactly the snapshot's
   distinct set, per-value record counts equal (a raw value
   outside the register FAILS here);
2. every filed disposition equals the recomputation from
   the artifact's own rules;
3. disposition record counts sum to 11,839 and value counts
   to 1,122;
4. every unmapped value carries a reason; every
   non-material value carries a code from the register's
   code list;
5. the artifact's filed aggregates equal the recomputed
   aggregates.

Execution result is recorded in the Stage 1 stage record
(`records/stage1-record-2026-11-06.md`), including the
seeded-failure proof (a copy of the register with one value
dropped must fail check 1, and does).

## 6. Bounds

- Lexical, not geological (§2); the grain is the
  catalogues' grain — whether it is the right grain for
  Stage 2's field definitions is Stage 2's act, not this
  register's claim.
- Bound to the pinned snapshot's values (§1); the CSV's
  material values are out of scope until a successor
  register covers them.
- Nothing in this register moves evidence between channels:
  it normalizes a culture-side field only (H1).

*This does not establish:* that the classes are the right
grain — only that the mapping is total, ruled, and frozen
for the stages that consume it. (T102's line, carried
verbatim.)
