Settling: what the ledger implies under the program's registered rules — candidate sign-value assignments checked against every anchor context they touch, with coverage and conflicts enumerated. System view Matrix Settling
Computed layer  A settling run creates only run records: no ledger entry, claim status, stage, score, or anchor assignment changes as a result of a run (C086-16). Ledger verdicts and settling outputs are different layers — a computed output never overrides a ledger state, and this panel never presents one as doing so.

Annotation — wireframe 05 · not part of the UI
Purpose
Spec 085's projection panel, conformed into Point 5's settling panel: run a registered candidate against the anchor contexts, read coverage/conflicts/forced readings, and compare incumbent vs challenger under the interchangeability discipline with the per-claim divergence list. All run numbers are the stored T405 records' real outputs.
Primary action
Open on the stored T405 comparison (decision Q7), or run a registered candidate/scope pair and read its run record.
Changed & why
Against 085's 03: the four constraint kinds (score floor, anchor consistency, support floor, contradiction tension) are gone — they belonged to 085's projected-constraint engine, which was never built and whose framing 086 superseded; the Experiment Builder stub that named it was removed with a pointer at Stage 4 closeout (T406). What replaces them is glossa-settle-1's actual rule set (S-R1–S-R4) over anchor contexts. The 085 score-ceiling table is likewise not carried over: ceilings were AEE propagation outputs, and under C086-16 displayed scores live on the claim view under the ScoringEngine label, not on this panel. What survives from 085: the run-record determinism note, the named-witness shape (a conflict names its context and pair), and the reach-stated-next-to-results card.
Spec claims
C086-15 (interchangeability: same pins, per-claim divergence list, expectations named or their absence generated), C086-16 (a run creates only run records; the layer labeling), C086-18 (run records carry their pins as as-of stamps). Scenario objects are run inputs only — nothing on this panel is a verdict input (gate V9 audits the separation).
